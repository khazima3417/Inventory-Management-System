# Inventory Management System
## Project Description
An Inventory Management System developed in Python using Object-Oriented Programming (OOP) and error handling.
The system manages products, branch inventory, transactions, stock valuation, sales analytics, product expiry, and inventory reconciliation.
## Features
- Product and branch inventory management
- Transaction validation and error handling
- Purchase, sale, customer return, supplier return, and transfer operations
- Stock valuation and company totals
- Sales analytics using transaction-time prices and costs, including customer returns
- Low-stock and reorder reports
- Product expiry tracking and batch/stock mismatch checks
- Physical and system stock reconciliation
- Safe JSON data loading and atomic saving
- Automated tests
## Technologies Used
- Python
- JSON
- Object-Oriented Programming (OOP)
- Exception Handling
- Unit Testing
## Project Files
- inventory_management.py — Main program
- test_inventory.py — Automated tests
- data.json — Inventory data
- output.txt — Sample program output
## How to Run
Run the main program:
python inventory_management.py
Run the tests:
python -m unittest test_inventory.py -v
## Purpose
This project demonstrates inventory management, transaction validation, reporting, JSON file handling, and error handling in Python.
